# Keyline

Keyline is a native macOS client for Outline access keys (`ss://` and `ssconf://`).

**Download:** the newest DMG is on the [Releases](https://github.com/PrimeSeventyThree/keyline-releases/releases/latest) page. Keyline updates itself after that.

**Problems or ideas:** [open an issue](https://github.com/PrimeSeventyThree/keyline-releases/issues/new). Keyline's "Send report" button opens one with the crash details filled in; nothing is sent until you submit it.

This repository only holds releases and bug reports. Keyline needs macOS 12 or later.

Keyline is an independent project and is not affiliated with or endorsed by the Outline Foundation or Jigsaw.
